Implemented locally:
- Legacy local password login fails closed; local SHA-256 credential creation
  and authentication removed. Company sign-in uses server authentication.
- Server-authenticated user refresh removes any old credential hash for that user.
- Logout revokes only the current device token before deleting local credentials.
  Network/server failure leaves the user signed in, retains data and restores
  foreground updates. An internet connection is required for secure logout.
- Server logout is idempotent for expired/revoked/unknown tokens and never trusts
  a submitted company/user/session identifier.

  MFA recovery material separately with controlled access.

  version and completion result without logging secrets or customer records.
- Enable retention/versioning or immutability when available. Agree retention
  and recovery targets before scheduling automatic removal of any backup.
- Restore into an isolated temporary environment with outbound mail disabled;
  verify database integrity, company isolation, totals and attachments, then
  securely remove only that explicitly identified temporary restore environment.
- Alert on failed/missing backups and periodically perform a full restore drill.
- An SSD connected to the same PC is not sufficient protection from loss,
  ransomware or theft; maintain an independent encrypted copy.
